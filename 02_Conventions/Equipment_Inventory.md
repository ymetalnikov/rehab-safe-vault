# Equipment Inventory

This document lists the tools and equipment used in rehabilitation exercises. Use these terms for filtering and exercise selection.

## Resistance Bands

Standardized levels for bands (based on typical color/tension):

- `Level 1` (Yellow/Extra Light) — Minimal resistance for early activation.
- `Level 2` (Red/Light) — For initial strengthening.
- `Level 3` (Green/Medium) — Standard resistance for most rehab exercises.
- `Level 4` (Blue/Heavy) — Advanced strengthening.
- `Level 5` (Black/Extra Heavy) — Late-stage power/strength.

## Household Items

- **Rolled-up Towel:** Used for elbow alignment and spacing.
- **Dowel / Stick:** Used for active-assisted range of motion.
- **Chair / Table:** Used for support (e.g., Pendulums).
- **Wall / Doorframe:** Used for resistance or stretching.

## Specialized Tools

- **Medicine Ball / Weighted Ball:** Small weighted balls (1-3 kg) for stability/plyometrics.
- **Gym Ball:** Large ball for stabilization exercises.
- **Dumbbells:** For progressive loading.

## Usage in Exercises

When adding an exercise, specify the required equipment from this list. This allows the system to recommend exercises based on what you have available.
