# Principles of Use

## 1. I define the protocol

The system does not invent a recovery plan. I add the exercises that have been prescribed to me or that I've decided to track.

## 2. Every exercise has a reference

Each exercise must have an "ideal version":

- a description of the technique;
- a video or link to an example;
- key movement points;
- common errors;
- exactly what to observe.

## 3. We track dynamics, not a single session

A single measurement may be noise. What matters is the trend across multiple sessions.

## 4. Honest uncertainty beats confident fantasy

If the video is bad, the shoulder isn't visible, the angle is wrong, or the movement can't be assessed — the system should say there isn't enough data.

## 5. The summary matters more than raw video

The main value is a concise session record and dynamics over time:

- what I did;
- how it felt;
- what improved;
- where the errors were;
- what recurs.
