# MVP

## MVP goal

Test a simple scenario:

> I define the exercises and the ideal performance, then track my progress session by session.

## Included in the MVP

### 0. First run and 2-week cycle

- fill in info about myself;
- set a 2-week goal;
- pick exercises for the cycle;
- after 2 weeks, review the trend and update the plan.

Details: [[Bootstrap_and_2-Week_Cycle]]

### 1. Exercise database

For each exercise:

- name;
- description;
- source;
- reference video/link;
- key technique points;
- common errors;
- what to track;
- weight/importance;
- restrictions;
- performance recommendations.

### 2. Protocol

- list of exercises;
- frequency;
- sets/reps/time;
- performance comments.

### 3. Session entry

During the session, the system doesn't distract.

After the session, feedback is collected separately for each exercise:

- date;
- which exercises were done;
- performed: yes/no/partially;
- pain before/after;
- sensations;
- approximate range of motion;
- notes;
- brief summary.

Feedback can be filled in later — for example, at lunch after a morning workout.

### 4. AI analysis as a recording aid

AI can help describe:

- whether the shoulder is visible;
- whether the video quality is sufficient;
- whether the trajectory resembles the reference;
- where compensation may be happening;
- which errors recur.

If there isn't enough data — it says so plainly.

### 5. Trend

Summary over a period:

- regularity;
- pain;
- range of motion;
- recurring errors;
- what improved;
- what got worse.

## Not in the MVP

- complex medicine;
- "what to do next" recommendations;
- cloud;
- social features;
- a full-fledged mobile app.

For now, Obsidian + templates + manual/AI summary is enough.
